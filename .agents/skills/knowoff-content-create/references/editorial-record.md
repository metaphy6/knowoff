# Editorial record

Use these fields in the existing planning document or worksheet when preparing
a batch for later curation. This is not a runtime schema, approval database or
requirement to add fields to the Contributor Studio. Source standards remain
in [Humor development](../../../../content/humor-development.md) and the
[Curator Guide](../../../../content/curator-guide.md).

## Batch context

- Editorial batch ID, requested scope, themes, target cultures and BCP 47
  languages, intended rating and media types; label provisional choices.
- Source documents/sections consulted and date or repository revision, noting
  relevant working-tree changes. Reference the documents instead of copying rules.
- Planned and completed static-image/plain-text counts for Nown and playable-card
  pools separately; note concepts. Captions, translations and planning prose
  are not extra text cards. Format follows the joke with no mandatory ratio.
- Consulted High/Distant/Chaos rules, current tuning and server/client source
  revisions from the [dealing path](../../../../content/curator-guide.md#read-the-dealing-path-before-authoring);
  distinguish the Blueprint guarantee from verified runtime behavior and open gaps.
- Freshness and tone mix observations stay separate from media priority; these
  planning records do not encode dealing weights or change pack schema.
- Actual generation provenance, output locations and human edits. A seed is
  recorded only when the tool supports and reports one.

## Candidate record

| Field | What to record |
|---|---|
| Candidate ID and revision | Stable editorial ID; link to the prior revision when rewritten. This is not yet an assigned runtime ID. |
| Role and content | Nown or playable card, language, text or actual local asset reference, theme and intended rating. |
| Media and delivery | Image or text; concept/source/completed asset; measured dimensions, bytes, static encoding, output reference and single-frame validation or **not run**. |
| Visual direction | Candid situation, rough crop/texture, abrupt visual joke and readable frozen moment; card-size compressed inspection result or **not run**. A downsized polished render is not lo-fi evidence. |
| Tone | Exactly one bucket from the current tone matrix. |
| Editorial dimensions | Human situation, comic mechanism, cultural reach, shelf life and accessibility/reference difficulty. |
| Relationship hypotheses | Related Nown candidate IDs, proposed High/Distant/Chaos relation, plausible interpretation, alternative explanation and risk of giving Nown away; measured bands, embedding model/version and actual scores recorded separately when available. No band labels appear on player-facing cards. |
| Provenance and rights | Original/generated/adapted source, author/model where known, source links, attribution/license evidence and unresolved rights questions. |
| Topical context | Source, observation date, intended regions/languages, one-sentence context, review date and expiry date; use not applicable for non-topical material. |
| Cultural adaptation | Linked language variants, what changed, local-meaning concerns and reviewer evidence. |
| Agent recommendation | Keep, rewrite, hold or reject with a specific reason; this is not human approval. |
| Evidence | Automated screen result, human review, playtests, certification and activation each have their own evidence reference or **not run** status. |

For real playtests, record table size, schedule, candidate versions, hands used,
recognition, laughter, alternative explanations and references needing explanation.
Distinguish observations from predicted reactions. Link official Portal/Admin
decisions instead of maintaining a second approval state. A weekly or expiry
review records the human's retain/rewrite/retire decision; a retirement reaches
the app only through a verified pack update.
