# How-to-play clip — text release brief

**Planning only.** Produce a ≤45-second clip from final production UI after the
text release gates pass. The baseline explains Missed the Briefing; each other
enabled mode gets its own brief action demo or localized help. This is a capture
brief, not an existing video or permission to imply unreleased modes are playable.
Rules derive from [Blueprint](../../BLUEPRINT.md), not the archived roadmap.

## Format

Real UI capture, silent-autoplay friendly captions, one idea per beat, readable
at phone size. Use the established display face and lime highlighter. Export
vertical 9:16 and square 1:1 derivatives, each ≤10 MB as an internal production
budget; verify actual store requirements before delivery. Captions accompany
accessible in-app written help; the clip is not the only rules explanation.

## Seven-beat storyboard

| Beat | Seconds | Visual | Caption draft |
|---|---|---|---|
| 1 | 0–5 | Four seats; a short text Nown appears on three phones, neutral placeholder on one. | One of you missed the briefing. |
| 2 | 5–9 | The same hold/release role check on every phone. | Check your role in secret. |
| 3 | 9–14 | An active Nower reads the short situation; Donower sees no secret. | Some know. Others bluff. |
| 4 | 14–21 | A response is selected, confirmed, then shown with the player's name. | Play a response you can defend. |
| 5 | 21–28 | Earlier responses remain in evidence; public draw count, Poke, short discussion. | Read the table. Make your case. |
| 6 | 28–36 | Attributed votes arrive live; a voter changes target before Ready/timeout; Nower is eliminated. | Vote carefully. A wrong vote costs. |
| 7 | 36–45 | Team verdict, public points and begun-round Nown reveal; rematch returns to settings/Ready. | Donowers win together. Ready again? |

No Shuffle, Reveal, free draw, Pass card or Revote specialty. Do not show public
per-match Noin balances or unreached future Nowns. Do not mix a card-action scene
from one mode with another mode's rules. For Scale show confirmed rating; Make
Room before/after slot; Bargains proposal and recipient response; Top That target
and attributed link. None uses an automated correctness/funniness judge.

## Capture and verification

Use human-operated test accounts in an isolated no-reward environment; updated
dev bots can assist only after mode/protocol tests, never as a disguised claim
about production backfill. Capture requires exact app/server/rules/pack/language
versions, no debug overlays or personal account data, and complete legal actions.
Inspect crops, caption timing, diacritics, text scaling and private-role cuts.
Use FFmpeg/FFprobe on PATH for encoding and verify duration/resolution/size;
watch the result. No capture, generation or video work is authorized by this
planning task. Publish only with the matching enabled release and localized copy.
